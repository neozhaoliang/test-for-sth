# 双木林叔 × 陈chensir：长期收益率估值方法知识库（v1）

> 类型：研究方法，不是对任何公司的事实认定或投资建议。整理时间：2026-10-08。以下为公开讨论的归纳与数学校正，非逐字转录。所有股价、ROE、派息率应使用决策日可用的数据。个人观点不得替代财报与监管公告。

## 1. 陈chensir：ROE—留存—股息—回报要求
设 r=可持续ROE，p=现金分红占可持续利润的比例（0≤p≤1），c=留存收益转化为可持续利润增长的效率（不能默认100%），b=市净率P/B，k=股权要求收益率（均按小数计）。
长期、稳定且可持续的简化模型：

g ≈ r(1-p)c
y = rp/b
k ≈ g+y + 估值变化的年化贡献

固定估值且无终止风险时，b* ≈ rp/[k-r(1-p)c]，前提分母>0且p>0。
若分母≤0，说明永续常增长模型不适用，不能输出无限大合理PB；需改用有限期现金流估值、显式终值和敏感性分析。
对应 PE*=PB*/r（r>0且盈利口径一致）。

关键思想：
- 同样净利润，ROE高且增长能兑现的公司可以有更高估值，但不能仅以高ROE推导高估值。
- 分红与留存要比较边际回报：低PB、再投资回报差时，提高可靠分红可能有利；高估值、再投资回报好时，提高分红未必有利。
- 临界PB约为1/c来自边际分析（在其他条件不变、永续模型适用时）；这不是所有公司统一的买点。
- 高分红不能替代低负债、真实经营现金流和分红可持续性核验。
- 要记录去年给出的合理价值区间及其当时假设，后续估值不得只因市场价格上涨同步上调。

## 2. 双木林叔：前瞻、周期、能力圈、横向比价
- 前瞻增长而非简单外推：辉煌历史增长应根据市场容量、竞争、盈利能力与资本投入折减为可持续增长。
- 周期股要用完整周期的盈利、运价/产品价和资本开支情景做估值，周期顶部的低PE可能是假便宜；利润变化与股价变化不线性。
- 银行等行业的未来ROE可以长期下降，不应以历史峰值ROE机械算买点。
- 多家公司放到相同税费、货币、股权风险和持有期限下比较预期总回报率；收益率高不等于风险低。
- 能力圈：对理解不足的药品研发等业务，允许明确“不具备可靠估值条件”，不能强行给目标价。
- 对比不同买入时点的未来回报，而非看持有人历史成本或历史回报率。

## 3. Agent 强制计算顺序
1. 基准日期、股价、股数、币种、净资产归母口径及全部数据来源时间。
2. 识别银行、周期、成长、受监管现金牛、医药研发等模式；核验会计质量、表外义务、商誉、资本开支、现金分红与回购区别。
3. 估算未来3–10年可持续ROE、派息率、留存增长效率（c）；给悲观/中性/乐观三情景和各参数理由。
4. 输出预期长期收益率分解：增长贡献g、现金分红收益y、估值变动贡献；单列股息再投资与税负假设。
5. 计算有限期现金流折现或终值校验；若永续公式条件不成立，显式标记不适用。周期股以全周期现金流、净现金/净债调整估值。
6. 对照最低要求收益率和同类替代投资；给买入安全边际、最多可承受的ROE下降及失效条件。
7. 检验与历史估值记录是否合理连续，解释所有因基本面或折现率变化导致的大幅修订。
8. 只有估值与市场价同期且可靠时才输出“高估/低估”；否则输出“无法判断当前赔率”。

## 4. 不得机械使用的边界
- 这是由增长分解与股息收益近似得到的**情景模型**，不是严格、普适的股权定价恒等式。
- 若留存资金沉淀、回购改变股数、资产减值、负债融资、ROE变化、摊薄或股息增长≠利润增长，g=r(1-p)c 可能失真。
- 对银行需关注真实资产质量与资本约束；医药需考虑专利悬崖和研发成功率；周期股需考虑资产寿命、供需周期与终点价值。
- 原作者对某个股票的评论是观点，不能直接继承为本次估值事实；也不将未核实主观论断写成“已证实”。
- 陈chensir提出“寿命终点折价”的观点，但公开举例的比例不能不经推导直接当成通用折现公式，应使用明确有限期限模型校正。
