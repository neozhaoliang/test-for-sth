# 项目代码结构

```
MediaCrawler
├── base
│   └── base_crawler.py         # 项目的抽象基类
├── cache
│   ├── abs_cache.py            # 缓存抽象基类
│   ├── cache_factory.py        # 缓存工厂
│   ├── local_cache.py          # 本地缓存实现
│   └── redis_cache.py          # Redis缓存实现
├── cmd_arg
│   └── arg.py                  # 命令行参数定义
├── config
│   ├── base_config.py          # 基础配置
│   ├── db_config.py            # 数据库配置
│   ├── bilibili_config.py      # B站配置
│   └── xueqiu_config.py        # 雪球配置 (用户 ID 列表)
├── database
│   ├── db.py                   # 数据库ORM，封装增删改查
│   ├── db_session.py           # 数据库会话管理
│   └── models.py               # 数据库模型定义
├── docs
│   └── ...                     # 项目文档
├── libs
│   └── stealth.min.js          # 去除浏览器自动化特征的JS
├── media_platform
│   ├── bilibili                # B站采集实现
│   └── xueqiu                  # 雪球采集实现 (输入用户 ID, 爬取全部发帖+回复)
│       ├── core.py             # 爬虫主流程 (含阿里云 WAF 滑块处理)
│       ├── client.py           # 浏览器页面内 XHR 数据客户端 (无 HTTP 模式)
│       ├── help.py             # 数据解析 (帖子/评论/用户)
│       └── login.py            # 登录 (可选, cookie 方式)
├── model
│   ├── m_bilibili.py           # B站数据模型
│   └── m_xueqiu.py             # 雪球数据模型 (帖子/回复/用户)
├── proxy
│   ├── base_proxy.py           # 代理基类
│   ├── providers               # 代理提供商实现
│   ├── proxy_ip_pool.py        # 代理IP池
│   └── types.py                # 代理类型定义
├── store
│   ├── bilibili                # B站数据存储实现
│   └── xueqiu                  # 雪球数据存储实现
├── test
│   ├── test_db_sync.py         # 数据库同步测试
│   ├── test_proxy_ip_pool.py   # 代理IP池测试
│   └── ...                     # 其他测试用例
├── tools
│   ├── browser_launcher.py     # 浏览器启动器
│   ├── cdp_browser.py          # CDP浏览器控制
│   ├── crawler_util.py         # 爬虫工具函数
│   ├── waf_slider.py           # 阿里云 WAF 滑块验证处理 (自动+人工)
│   ├── utils.py                # 通用工具函数
│   └── ...
├── main.py                     # 程序入口, 支持 --init_db 参数来初始化数据库
├── recv_sms.py                 # 短信转发HTTP SERVER接口
└── var.py                      # 全局上下文变量定义
```
