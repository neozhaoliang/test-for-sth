# 有主见的投资 Agent：研究方法与实现边界

## 定位

它不是十二维度平均分、评级阈值或机械择时信号生成器，而是具备投资风格与
独立解释能力的研究助手。投资风格可以有倾向、会误判，也不必迎合任何作者或用户
事先的结论，但每一条可核对事实必须有相应时点的数据依据。

最终呈现的是该股票**当前价格下最重要的投资矛盾和明确观点**。
利润增长、减持、资本开支、市场风格、现金流、周期、行业竞争、地缘政策等
不是等权选票。少数关键因素可以主导观点，反之多项相关风险也不能简单相加。

## 三类职责

**事实层（不可主观编造）**：价格有效性、发行股数、减持是否执行、公告
生效日期、融资盘、利润/现金流、项目回款、分红是否真实派发、政策法律效力。
程序负责时点隔离、单位与数据口径验证、隐私过滤、重复事件去重。

**方法层（允许竞争和犯错）**：从私有投资知识库提炼可迁移的思想，例如
市场风格的反身性、科技股融资的股东成本、股息和留存资本的边际回报、
完整周期盈利正常化、现金流兑现及资本支出回报。不同方法可以彼此冲突，
应保留其适用情景、可能失误和公司层面的核查问题，不把来源作者名和原帖内容
直接推送给公开股票报告。

**判断层（模型真正做主）**：选取本公司、当期价格下最有解释力的方法，
可否定已提炼方法、可形成强烈看多/看空观点，也可主动给出中性结论。
风险观察或十二项描述性评分不得覆盖模型产生的 `stance`。
公司长期经营质量与当前股票投资赔率可不同。

## 代码路径

- `analysis/market_research_context.py`：匹配匿名化的研究原则和有日期的市场事件。
- `analysis/investment_method_distiller.py`：私有摘录 → 模型提炼候选投资方法；
  输出需要经过作者/原帖/外部股票/长段复述检查；失败时使用已审核的匿名原则。
  科技领域优先考虑长期融资/股东利益方法而非最新14帖。
- `analysis/report_synthesis.py`：将候选方法交给股票研究模型自由取舍；
  不再调用强制看空/看多的后处理。
- `analysis/position_risk.py`：保留日期匹配的事实和风险观察，
  不再根据独立因素个数自动设定方向；旧 `enforce_asymmetric_odds`
  仅为向后兼容的无操作函数。
- `analysis/report_contract.py`：研究覆盖多方面，但合成结论须提出核心矛盾；
  二次审查只纠正事实/口径、不能因争议本身压回中性。
- `analysis/public_report.py`：公开报告输出字段白名单与知识库身份、原帖复述防护。
- `web/app.py`：12个方面的倾向图仅是描述，非综合决策权重。

## 本次不宣称已完成的能力

1. 提炼方法和股票研究仍可能受大模型偏差影响；**保留主观性不代表模型正确**。
   需要时间点样本对照投资观点变化、未来结果和决策一致性。
2. 当前每次新的完整研究仍可能调用知识提炼模型；多用户商业部署应将“方法卡”
   离线版本化，并将统一股票报告定时发布，避免每个查询重跑。
3. 不对单一作者的观点进行立场灌输，更不能反向把一种市场风格固化成永久规则。
   学习的是可迁移方法，作者身份与原帖留在私有知识系统，不进入客户报告。
