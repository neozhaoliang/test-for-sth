# 行业差异化估值与A股/美元/美债风险传导（v1）

**原则**：代码能计算的仅是“输入假设条件下的股权价值”，不是自动发现市场公允价。缺失现金流、账面权益、监管资本、资本开支或来源时必须明确拒绝输出目标价。严禁使用此前因 `k-g≈0` 产生1366元价格的永续ROE/PB公式自动定价。

## 1. 行业模型选择

| 公司经营模式 | 主模型 | 不应替代的事实 | 交叉验证 |
|---|---|---|---|
| 银行 | Clean-surplus 残余收益：`B0 + Σ(ROE-k)B/(1+k)^t`，预测期后超额ROE=0的审慎终值 | 资本充足率、净息差、不良、拨备、普通股净资产及分红口径 | 可兑现现金股息 |
| 券商等非银 | 调整后的残余收益 | 金融资产公允价值、杠杆、流动性与监管资本 | 资产质量；保险另列模型 |
| 保险 | **当前不自动定价** | 真实内含价值、精算利率、死亡率/退保率、偿付能力 | 经审计EV/新业务价值敏感性 |
| 电力/核电、水务、燃气、高速 | 未来分红折现（股息必须由FCFE覆盖） | 上网电价/电力市场化、燃料成本、资本开支、项目债务；核电退役义务 | 股权自由现金流 |
| 煤、油、矿、航运、化工等周期 | 至少5年完整周期证据支持的中周期FCFE折现 | 可持续商品价、成本、矿山寿命/航运运力、维持性CAPEX、营运资金 | 资产净值/中周期盈利 |
| 软件、半导体、先进制造 | 显式FCFE折现 | 可验证订单、研发质量、现金回款、股权激励、客户集中及二供替代 | 可核实长期现金能力 |
| 消费品牌 | FCFE折现 | 品牌价格、渠道库存、现金转换和持续资本投入 | 现金股息 |
| 房地产/资产型 | 调整后NAV：可实现资产－全部义务－变现税费 | 土储估值、负债、预售义务与表外担保 | 项目现金流 |

## 2. 算法与保护

**FCFE**：先预测3—15年的每股股权自由现金流（而不是营业现金流），加上独立预测的下一年正常FCFE，通过股权要求收益率折现。确保终值增长率不大于4%，且 `k - g ≥ 4个百分点`。**这是一个模型上限，不是公司增长能力证据**。终值价值占比超过70%发出警告，任何无限增长/分母接近零情形拒绝。

**银行残余收益**：普通股期初调整净资产 + 显式3—15年经清洁盈余约束的超额ROE折现。期限结束后的超额ROE暂按零处理，不假设资本优势永久存在。任何优先股、增发、OCI或分红资本约束未明确时不应当做高置信度结果。

**周期/电力**：中周期FCFE需要跨越5年以上经济周期且有维持性CAPEX依据；受监管企业的预测股息不得超过可覆盖的现金流。对于电力，不能把发电量/会计净利润直接当股东自由现金流。

**计算单位**：所有每股金额均采用 `CNY/share`，否则必须事先依据可追溯汇率与股份数换算。投入计算的每个输入，必须记录其发布日期、来源（已披露值）或明确的假设依据（预测值）。

## 3. A股市场、中国环境、美元/人民币与美债利率

这些属于**公司现金流和定价环境的两个不同层面**，要分别处理。

- **中国经济与政策**：行业监管价格、能源安全、国企资本回报考核、地方政府/地产相关需求、融资成本、税费、IPO/再融资、限售解禁、国资资本配置。国企属性、牌照与政策风险必须有来源，不能根据名称自行推断。
- **A股风格**：跟踪上证红利、科创50、创业板、沪深300相对收益、历史估值分位、ETF与公募流向；只能生成有日期的“市场定价风险情景”，不能让科技/红利风格涨跌自动变成企业现金流增长。风格切换可能影响持有期市场价值，但不等于长期股权内在价值变化。
- **美元兑人民币**：核对外销结算币种、外币成本、进口设备、海外资产、美元债、套期保值。海外收入比例只是敞口筛查线索，不是 `净利润 × 升贬值幅度`。
- **美债10年期收益率**：检查美元融资、全球风险偏好及同业估值，但人民币投资者要求收益率不能机械使用美债利率；防止与其他风险溢价重复计算。
- **国内利率**：LPR仅为贷款报价利率，不能直接当作国债无风险利率或央行政策利率；应区别政策利率、国债收益率、公司实际债务期限与股权资本成本。
- **外部冲击**：出口限制、关税、海外客户资本开支、海运费、能源价格、汇兑损益、外资和全球产业链竞争，结合公司收入/现金流结构和监管事实逐一核验。

数值压力测试支持**显式、带来源的公司层面敏感度系数**（比如美元兑人民币变化1%对FCFE的影响），并记录单位和校准时间。没有这些系数，报告保留“无法量化”，不捏造目标价加减幅度。

## 4. 运行方式：模型会自动选，估值不会凭空编

日常运行原股票助手无需新命令。若缺少完整预测，WebUI 会优先展示可用的历史已实施派息参考价、历史PB中枢及长期ROE参考；同时明确完整行业FCFE尚未独立预测，禁止把这些参考价冒充内在价值。

要复算**人工核实**的公司预测，可将 `config/valuation_cases.example.json` 复制到 `config/valuation_cases.local.json`，把六位股票代码、报告基准日、预测的每年FCFE/终值及逐项来源改为实际内容。新文件应仅在本机管理，不提交Git。历史模式要求配置的 `as_of` 与回测日期完全相同，且所有数据 `available_at` 不晚于该日期。

**字段必需类型**：
- 技术/消费/综合：`annual_cash_flow_per_share`（3—15年）、`terminal_cash_flow_per_share`、`required_return_pct`、`terminal_growth_pct`。
- 周期：上述字段外加 `cycle_span_years`（至少5）和 `maintenance_capex_basis`，附来源。
- 受监管分红：`annual_dividends_per_share`（3—15年）、`terminal_dividend_per_share`、`required_return_pct`、`terminal_growth_pct`、`dividend_coverage_by_fcfe`。
- 银行/部分非银：`opening_book_per_share`、`annual_roe_pct`、`annual_payout_pct`、`required_return_pct`、`capital_adequacy_verified=true`。
- 资产型：`fair_assets_per_share`、`total_obligations_per_share`、`realization_tax_and_cost_per_share`。

每个字段都需 `provenance[field]` 对应 `available_at`。已披露财务事实需提供 `source_url`，预测/政策假设需提供 `assumption_basis`；每股货币指标需明确 `unit: "CNY/share"`。

## 5. 现金流未预测齐全时的投资者参考估值（2026-10-10起）

**不能再把“无法完整DCF”写成“完全不能估值”。** 在完整行业估值的同时，后台
`analysis/investor_valuation.py` 提供独立、可重现的几种参考口径：

1. **现金股息收益率锚**：只读取已经实施的现金分红，不把回购混进分红；按公告公历年聚合，同一公告日期与金额去重，排除预案/未实施。本公历年尚未结束，不当作完整年。取近年已实施派息年份中位数，给出分红乘数0.70 / 1.00 / 1.15与股息要求7.0% / 5.5% / 4.5%的三种**演示情景**。`P_reference = repeatable_DPS / investor_required_yield`。这不是因果预言，不可称已审计内在价值；未出现实施记录的年份可能包含未分红年份，不能凭样本缺失断言稳定性。只有一个年份或无法确认实施状态时不强行补数。
2. **历史PB中枢对应价**：若有超过100个历史观测及日期匹配的每股净资产，用历史PB中位数乘当期账面净资产，形成一个*历史市场定价参照*，并明确不保证估值回归。业务、政策或盈利能力变化时，旧中枢可能失效。
3. **跨周期ROE盈利收益率参照**：至少三个完整年度的ROE中位数乘目前账面净资产除以股价，只用于理解当下支付的价格相对长期权益回报，不能等同实际股息或股权自由现金流。

对煤电、航运、矿业、公用事业等公司，应同时把**当期相对过去3—5年的盈利、现金流、产品/燃料价格与分红覆盖能力**纳入结论。若缺少维持性资本开支和净融资数据，只列情景参考价，不称最终“合理目标价”。

2026-10-09公开市场快照已作为有来源、有日期、21天有效期的事件存入
`data/market_events/dividend_style_2026_10.json`。最近的红利基金大额申购限制只能提示热度/容量压力，不能直接等同顶部、净流入或个股上涨。
市场风格优先以最近20个交易日上证红利相对科创50/创业板指涨跌表现衡量；
历史不足才回退有日期的YTD。股票研究同时查找最近120天的老木匠等KOL相关主题帖子，保留作者、原文、发布日期作为待验证假设。帖子未入库或未检索到时必须如实标缺。

**当前没有做**：对未来每年实际可分配股息的独立预测、对所有基金限购/新发公告的持续自动采集、对所有KOL帖子事实准确性的自动证实；固定收益率仅为投资者敏感性假设，不是“市场当前应有股息率”。

## 6. 验证限制与未完成工作

1. 新模块是**已实现的公式和严格输入门槛**，不是“公司现金流预测已全部自动提取完毕”。真实FCFE需要实际经营现金流、维持资本开支、融资、营运资金和稀释等数据；此阶段不会把净利润自动冒充FCFE。
2. 公司分部、多币种、一带一路项目、国企政策资产、矿产储量、受限资金、核电退役负债与银行资本不能由现有API直接推断，仍需一手文件和分析师情景。
3. 缺少财年口径/公告时点或校准的外汇利率beta时，报告仅显示风险渠道与数据缺口；**不能因为缺数据反向断言风险不存在**。
4. 因行业差异，任何单一模型结果都不等于确定的“正确价值”；当第二套独立模型缺数据，报告明确写“交叉验证未运行”，而不是伪造验证结果。
5. Python模型和前端敏感性图需要CI/真实股票验收；部署前应验证最新提交的测试结果。
